## Talking Points During Demo

- **"Why file storage?"** — Zero server dependency, works in any environment, easy to demo live. MySQL integration is ready in `database/schema.sql` — just install the connector.
- **"How is the password stored?"** — SHA-256 hash via macOS CommonCrypto. Only the hex digest is in `data/admins.dat`.
- **"Can I see the data files?"** — `cat data/books.dat` — human-readable pipe-delimited format.
- **"What if I enter invalid input?"** — Try entering "abc" for a numeric field — the app asks again without crashing.
- **"How would you add MySQL?"** — Set `STORAGE_MODE=mysql` in `.env`, install MySQL Connector/C++, recompile. The service layer doesn't change at all.
